# Embedding

## 1. How to embed videos

### Step 1

`git clone -b llei https://github.com/Peggy1210/eecs545-final-project.git`

### Step 2
Put the videos to be embedded in folder `videos`.

### Step 3
Run the notebook(recommended) or `video2img.py`.
You may find duration info of each video in `basic_videos_info.json`

## 2. HOW to use scrapping
The videos will be downloaded and embedded by patch (`num_of_patch` files each)
### Step 1
Ensure you have google chrome installed.
### Step 2
Find downloaded videos in your chrome download path.The default download path for google chrome in MAC is `downloads`. 
## Step 3
Follow the instructions of input prompt.
