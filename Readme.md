# Embedding

## 1. How to embed videos

### Step 1

Ensure putting the files into proper folders. The functional folder structure should be like this

+embedding
    +test.ipynb
    +video2img.py
+videos
    +gui_world_104.mp4

### Step 2
Put the videos to be embedded in folder videos.

### Step 3
Run the notebook(recommended) or `video2img.py`.
You may find duration info of each video in `basic_videos_info.json`.
